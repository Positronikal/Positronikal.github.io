# Positronikal.github.io

GitHub Pages site for [Positronikal](https://github.com/Positronikal). Served at
[positronikal.github.io](https://positronikal.github.io).

Built with [Jekyll](https://jekyllrb.com/) and the
[Minima](https://github.com/jekyll/minima) theme.

## Development

```sh
bundle install
bundle exec jekyll serve
```

The CI pipeline is `hooks/ci-check.sh` — run it locally before pushing.

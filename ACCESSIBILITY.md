# Accessibility

The Positronikal website follows Web Content Accessibility Guidelines (WCAG) 2.1 Level AA.

## Standards

- Semantic HTML elements are used throughout
- All images include descriptive `alt` text
- Color contrast meets WCAG 2.1 AA minimum ratios
- Content is keyboard-navigable
- Text is resizable without loss of functionality

## Reporting Issues

If you encounter an accessibility barrier, please open an issue at
[github.com/Positronikal/Positronikal.github.io](https://github.com/Positronikal/Positronikal.github.io/issues)
or email `admin@positronikal.tech`.
